Real-Time Network Threat Detection With A Live SOC Dashboard

NetSentinel captures or simulates traffic, detects suspicious activity in real time, stores telemetry, and visualizes everything in a fast browser dashboard.

View Repository See What It Tracks

Detection Rules

Port scans, brute-force attempts, DNS tunneling, and data exfiltration spikes.

Modes

Simulation mode for no-root demos and live capture mode with Scapy.

Engineering Quality

CI on 3 Python versions, Docker build checks, CodeQL scans, release workflows.

What It Does

Ingest

Consumes packet data from either Scapy live sniffing or synthetic simulation traffic.

Analyze

Applies sliding-window threat rules and cooldown logic to reduce alert noise.

Visualize

Presents alerts, protocol breakdowns, top source IPs, and traffic trends in real time.

Demo Flow

  1. Launch simulation mode (`python run.py --mode simulation --port 5050`).
  2. Open dashboard and watch packet stream populate instantly.
  3. Observe injected attack patterns trigger alerts in real time.
  4. Review alert severity, protocol distribution, and top talkers.
git clone https://github.com/elliottluftman/NetSentinel.git
cd NetSentinel
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py --mode simulation --port 5050
